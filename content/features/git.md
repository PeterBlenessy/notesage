## [web]

**A safety net for your writing.** Because your notes are plain files, they work beautifully with git. Notesage shows which files changed, lets you commit and switch branches, and can review the differences between versions right in the editor — no terminal required.

## [in-app]

If a folder is a git repository, Notesage shows file status in the sidebar and offers commit, branch switching, and a visual diff review. Compare the current branch against another and accept or reject changes hunk by hunk, all inside the app.

## [social]

Your notes are plain files, so git just works — see changes, commit, switch branches, and review diffs without ever leaving Notesage.
