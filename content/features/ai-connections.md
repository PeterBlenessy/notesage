## [web]

**Works with the AI you already use.** Notesage doesn't lock you into one assistant. Connect Claude, ChatGPT, Copilot, Gemini, or Codex with the account you already have, point it at a local model, or use the built-in offline assistant that ships with the app. Keys are stored in your Mac's secure keychain, never in a file.

## [deep]

### What it does

Notesage is deliberately model-agnostic. Instead of a built-in AI you can't change, you connect the assistants you already have — and switch between them per task or per project. Your API keys live in your Mac's secure keychain; the app never writes them to a file or sends them anywhere but the provider you chose.

### Four ways to connect

- **Bring your own key** — a key from Anthropic or OpenAI, pay-as-you-go.
- **Use a subscription** — sign in with Copilot, Gemini, or Codex.
- **Run locally** — point at a model on your own machine.
- **Bundled model** — an offline assistant that ships with the app; no account, no key.

### Pick the right tool per job

Different work wants different models: a frontier model for a tricky rewrite, a fast local one for quick help, an offline one for confidential material. You can route each use — chat, agent tasks, inline completions — to a different connection, and even lock a project to a single provider so sensitive work never touches another.

### Example

A consultant keeps a cloud model for everyday drafting but locks their most sensitive client's project to the offline bundled model — so that client's text is guaranteed never to leave the Mac, while everything else stays fast and capable.

### When to use it

Whenever "which AI?" has more than one answer: cost, quality, privacy, or offline access all point to different models at different moments.

### Tips

- Step-by-step setup for each provider lives in the in-app connection guide.
- Removing a connection deletes its key from the keychain immediately.
- Start with the bundled model if you just want to try things — it needs nothing.

## [in-app]

Open **Settings → Connections → Add Connection** and pick a provider. Paste an API key (Anthropic, OpenAI), sign in with a subscription (Copilot, Gemini, Codex), point at a local server, or enable the bundled model. The connection guide has step-by-step setup for each provider.

## [social]

Bring your own AI: Claude, ChatGPT, Copilot, Gemini — or run one fully offline. No new account, and your keys stay in your keychain.
