# Notes on Craft

A running collection of things worth remembering about the work.

- Write the boring first draft. You can only edit what exists.
- Cut the sentence you are proudest of; it is usually showing off.
- A paragraph is a single thought that has learned to breathe.
- When stuck, describe the problem to an imaginary reader — the answer is often in the describing.

## On revision

Revision is not fixing mistakes. It is discovering what you meant. The first draft is a question; the last draft is the answer you didn't know you had.
