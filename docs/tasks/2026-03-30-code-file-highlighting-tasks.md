### #3 — Create language registry module

**Description:** Create `src/lib/codemirror-languages.ts` with the extension → language mapping, lazy loader, `isCodeFile()` check, and `getLanguageName()` display name resolver. Each entry in the map is a dynamic `import()` that returns a `LanguageSupport` instance.

**Acceptance criteria:**

- `isCodeFile("main.ts")` → `true`, `isCodeFile("readme.txt")` → `false`

### #5 — Create CodeEditor component

**Description:** Create `src/components/editor/viewers/CodeEditor.tsx` — an editable CodeMirror 6 editor for code files. Follow the patterns from `SourceEditor.tsx`: create `EditorView` on mount, use `updateListener` with `settingContent` flag to dispatch changes to `updateTabContent()`, Cmd+S keymap for save, `Compartment` for dynamic language loading.

Key differences from SourceEditor:

- No markdown language — uses dynamically loaded language from `codemirror-languages.ts`
- No frontmatter support
- No ghost text / Copilot integration (can be added later)
- No AI bubble menu (can be added later)
- No view mode toggle keybinding
- Uses `notesageCodeExtensions` instead of `notesageHighlightStyle`

**Acceptance criteria:**

- Renders CodeMirror with line numbers, fold gutter, bracket matching, active line highlight, selection match
- Editable — typing, pasting, deleting, undo/redo all work
- Cmd+S calls `saveFile()` prop
- Content changes dispatch to `updateTabContent()` via updateListener
- `settingContent` flag prevents feedback loops on programmatic updates
- Language loaded dynamically via `loadLanguage()` on mount
- Language compartment reconfigured when language loads
- Content replaced when `content` prop changes (e.g., external file change)
- `notesage:find-open` event forwarded to `openSearchPanel()` (CodeMirror search)
- EditorView destroyed on unmount
- Full width layout (no max-width constraint)

**Complexity:** L **Category:** frontend **Dependencies:** Depends on #3, #4 **Files:**

- `src/components/editor/viewers/CodeEditor.tsx` — new file
