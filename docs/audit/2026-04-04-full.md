## 1. Memory Leaks & Resource Cleanup

### HIGH: useDirectApiChat — Listener Registration Race

**File:** `src/hooks/useDirectApiChat.ts:350-444`

The `ai-stream-done` listener is registered AFTER the `Promise.all()` for other listeners. If the done event fires before this listener attaches, it will be missed, leaving other listeners active indefinitely.

**Fix:** Include the `ai-stream-done` listener in the `Promise.all()` array.

### MEDIUM: useAcpLifecycle — Stale Listener During Cancel Escalation

**File:** `src/hooks/useAcpLifecycle.ts:623-650`

Cancel escalation listener can leak if the timeout fires before the listener promise resolves.

**Fix:** Use a mounted flag to guard the listener callback.

### MEDIUM: useMcpOperations — Listener Callback Not Mount-Guarded

**File:** `src/hooks/useMcpOperations.ts:140-164`

The `mcp-server-status` listener callback doesn't check mounted state. Events during unmount trigger unnecessary store updates.

**Fix:** Add `if (!mounted) return;` at top of listener callback.

### LOW: useActionScanner — Listener Race on Unmount

**File:** `src/hooks/useActionScanner.ts:30-61`

Listener cleanup uses `.then()` without mount guard. Minor — listener leaks are short-lived.

**Fix:** Add mounted flag pattern.

### LOW: useSpeechRecognition — Mount Guard Timing

**File:** `src/hooks/useSpeechRecognition.ts:77-100`

Code is safe due to generation guard but could be clearer. Documentation improvement only.

### Confirmed Good Patterns

- useLocalCompletion: AbortController for in-flight requests
- useFileWatcher: Debounce map overflow guards (MAX_DEBOUNCE_ENTRIES)
- useAppLifecycle: Comprehensive listener cleanup
- Page Breaks Extension: Proper Zustand subscription cleanup
- useSandboxViolations: Correct mounted flag + then-guard pattern
- All Rust processes: kill_on_drop(true), RunEvent::Exit hooks, orphan cleanup

## 2. Async Flows & Race Conditions

### MEDIUM: ACP Agent State Race During Reconnection

**File:** `src/lib/ai/acp-agent-state.ts:94-104`

`ensureAcpAgent` can recurse unboundedly if multiple callers rapidly change connections. The spawn promise dedup works but has no depth limit.

**Fix:** Add recursion depth limit or serialize spawn attempts.

### MEDIUM: Task Agent State Race During Respawn

**File:** `src/hooks/useAgentTaskOperations.ts:84-94`

Same pattern as ACP agent — unbounded recursion risk on rapid project switching.

**Fix:** Same as above.

### MEDIUM: Missing Cancellation on Stale Whisper Listeners

**File:** `src/hooks/useSpeechRecognition.ts:42-111`

Rapid mic toggle can leave dangling event listeners if listener setup fails mid-chain.

**Fix:** Use await + try/catch instead of fire-and-forget .then() chains.

### MEDIUM: File Watcher Debounce Map Growth

**File:** `src/hooks/useFileWatcher.ts:156-164`

The `modifyDebounce` map grows without bounds under extreme file churn. Guard at 500 entries is reactive.

**Fix:** Use time-based expiration or LRU map.

### MEDIUM: iCloud Discovery Debounce Map Growth

**File:** `src/hooks/useFileWatcher.ts:91-98`

Same unbounded growth issue as modifyDebounce.

### MEDIUM: RAF Progress Throttling Race in Recording Store

**File:** `src/stores/recording-store.ts:58-81`

Module-level RAF callback can reference stale store if recreated during hot reload.

### MEDIUM: Missing Abort Signal on Direct API Stream Listeners

**File:** `src/hooks/useDirectApiChat.ts:357-420`

If `ai_chat_stream` completes before all listeners finish attaching, events can fire after cleanup.

**Fix:** Use AbortController to cancel pending listeners on cleanup.

### MEDIUM: Stale Closure in Comment Delegation Callbacks

**File:** `src/hooks/useCommentDelegation.ts:71-172`

Callbacks capture full `comment` object. If comment is edited between task start and completion, stale data is used.

**Fix:** Capture `comment.id` separately instead of full object.

### LOW: Listen Promise Chaining Without Await in useFileWatcher

**File:** `src/hooks/useFileWatcher.ts:194`

`unlistenBatch.then()` may not execute if effect cleanup runs before promise resolves.

### LOW: Module-Level Timer in useAcpLifecycle

**File:** `src/hooks/useAcpLifecycle.ts:32-73`

Module-level `unresponsiveTimerId` shared across multiple hook instances could interfere.

### LOW: Missing Error Boundary in Comment Editor Sync

**File:** `src/hooks/useCommentEditorSync.ts:98`

`setTimeout` callback has no error handling for `setActiveComment`.

### Confirmed Good Patterns

- Promise deduplication for spawn (acpSpawnPromise, taskSpawnPromise)
- Proper stream cleanup via cleanupRef pattern
- Mounted check pattern in useGoalsDiscovery, useSpeechRecognition
- AbortController in cascading tool calls
- Event deduplication in useFileWatcher batch listener

### LOW: ChatPanel activeConvTitle

"No agent tasks yet" with no hint on how to create one.

### LOW: No Graceful Degradation When Ollama Not Running

### LOW: Corrupt Project Metadata Silently Reverts

### LOW: Git Status Errors Don't Indicate Stale Data
