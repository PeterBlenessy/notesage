A bug report authorises the WHOLE loop: review, fix, merge, release. Stopping
partway to ask is requesting permission that was already given.

**This covers merging the agent's own green PRs.** After reporting three PRs as
"green and waiting on you", the operator answered: if they are done, merge
them, then go on and fix the ones you recommended.

**How to apply:** a PR the agent authored that is done — CI green,
self-reviewed, no known gaps — gets merged without a further prompt. Report
what landed, not what is waiting. Still stop for genuinely outward, irreversible
steps the operator has reserved.
