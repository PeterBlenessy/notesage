# Drawing Examples

Examples are split into separate files so each can be read independently:

- `examples/flowchart.md` — Simple 3-box flowchart (Start → Process → End)
- `examples/architecture.md` — 4-box architecture diagram (Frontend → API → Database + Cache)
- `examples/process-flow.md` — Process flow with diamond decision node and branching

Each file contains a complete, compact Excalidraw JSON using only the required fields (defaults omitted). Copy any example and modify the element IDs, positions, text, and colors to fit your diagram.
